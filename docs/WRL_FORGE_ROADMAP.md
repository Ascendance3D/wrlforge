# WRL Forge Roadmap

WRL Forge is a source-first VRML97 authoring environment.
The exact source text remains canonical.

Execution and QA state:
GitHub Project: **WRL Forge Development** — <https://github.com/orgs/Ascendance3D/projects/1>

This file is a short projection of that Project. Lane scope, sub-issues,
dependencies, QA verdicts and status live in GitHub, not here. A lane appearing
here does not authorize work on it.
